# python-isinstance-issubclass-type-checking
A Python OOP exercise demonstrating inheritance-aware type checking using isinstance() and issubclass() with Animal and Dog classes.
<br>
Topics Covered:
<br>

1. Object-Oriented Programming (OOP) – Defining and using Python classes.
2. Inheritance – Creating a child class from a parent class.
3. isinstance() – Checking whether an object is an instance of a class or its subclasses.
4. issubclass() – Checking whether a class inherits from another class.
5. Type Inspection – Understanding relationships between objects and classes.
6. main() Function – Organizing program execution.
